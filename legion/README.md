# LEGION TIER

Five locks. Each one opens the next.

You have already picked the first one, or you would not be reading this. That
base64 string in your messages was not a warm-up, it was the first exercise,
and you did it before you had installed anything at all.

## The rule

Every file here tells you the name of the next one. There is no menu, no
index, and no way to skip ahead to the one that looks interesting. If you are
stuck, you are stuck on exactly one thing, which is a much better position
than being stuck on all of it.

Start with `01_base.txt`.

## What you will need

Nothing you do not already have. Every lock here opens with something already
sitting on the machine: `xxd`, `tr`, `file`, `strings`, and a terminal. No
Ghidra, no debugger, no downloads.

That is the point of this tier. Before you can take a program apart, you have
to stop being surprised by the shapes data comes in.

## If you get stuck

Read the top of the file again. Every lock carries its own hint in the first
few lines, in plain text, deliberately. Nobody is going to hand you the
answer, but nobody is going to leave you outside either.

The last one leaves you holding a code. Keep it.

## Where this goes

Level one is encodings: things wearing costumes. Level two is the twelve
missions, where the costumes come off and you start reading actual programs.
The last lock here ends on `strings`, which is exactly where mission 01
begins. That is not a coincidence.
